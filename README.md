# Time Series Foundation Models – Study & Implementation Collection

This repository contains my organized study notes, summaries, and small implementation work for several **Time-Series Foundation Models**.  
These models represent the newest approaches to forecasting, classification, representation learning, and general-purpose time-series understanding.

Each folder contains:
- A structured README explaining the model  
- Key ideas and architecture  
- Strengths & limitations  
- Notes from the original paper  

---

## 📘 Included Models

### 🔹 MOMENT (ICML 2024)
Univariate Time-Series Foundation Model trained with masking & reconstruction.  
Focus: general-purpose representation learning.

➡️ [Open Folder](./MOMENT%20(Time%20Series%20FM))

---

### 🔹 Moirai (Times Series Forecasting FM)
Large-scale model for universal time-series forecasting across many domains.  
Focus: patch-level forecasting with frequency-agnostic design.

➡️ [Open Folder](./MOIRAI%20(Time%20Series%20FM))

---

### 🔹 Moirai-MoE
Extension of Moirai using a **Mixture-of-Experts** architecture.  
Achieves better generalization and frequency-invariant representations with fewer active parameters.

➡️ [Open Folder](./MOIRAI-MoE)

---

### 🔹 TimesFM
Google’s foundation model for scalable and domain-general time-series forecasting.  
Focus: efficient multi-horizon forecasting at scale.

➡️ [Open Folder](./TimesFM%20(Time%20Series%20FM))

---

### 🔹 Mantis
Classification specific time-series foundation model

➡️ [Open Folder](./Mantis%20(Time%20Series%20FM))

---

### 🔹 SleepFM
A specialized sleep-stage classification model

➡️ [Open Folder](./SleepFM)

## 🎯 Purpose of This Repository
This collection exists to help me:

- Build intuition for **general-purpose time-series architectures**  
- Compare how each model handles frequency, scaling, and multi-task learning  
- Use these ideas in my own projects (e.g., sleep stage classification with MOMENT)  
- Prepare for future research or graduate-level work involving foundation models
